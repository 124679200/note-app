# 我的编辑笔记（可编辑单页应用）

一个纯前端的单文件网页应用，打开就能编辑，**无需服务器、无需安装**。

## 功能

| 分类 | 功能 |
|---|---|
| 文字编辑 | 加粗、斜体、下划线、删除线、字号、字体、文字颜色 |
| 快捷键 | `Ctrl+B` 加粗 · `Ctrl+I` 斜体 · `Ctrl+U` 下划线 |
| 卡片 | 添加 / 删除卡片，标题与正文均可编辑 |
| 图片 | 上传图片，自动压缩（支持大原图） |
| 外观 | 6 种背景色 + 自定义背景色 + 暗色模式 |
| 数据 | 改动自动保存到浏览器本地，刷新不丢失 |
| 导出 | 一键导出为独立 HTML 文件 |

## 使用

直接用浏览器打开 `index.html` 即可。

## 数据存在哪里

数据保存在**你自己浏览器的 localStorage / IndexedDB** 里，不会上传到任何服务器。

⚠️ 这意味着：
- 换浏览器、换电脑、清理浏览器数据 → 内容会丢失
- 重要内容请用工具栏的 **💾 导出** 生成 HTML 文件备份

## 技术说明

- 单文件应用，所有 CSS / JavaScript 内联在 `index.html` 中，零外部依赖
- 文本格式通过 `document.execCommand` 作用于选区
- 图片本体存于 IndexedDB，localStorage 仅存引用，避免 5MB 配额限制
- 存档同时保存纯文本与 HTML，兼容旧数据并保留富文本格式
